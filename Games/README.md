# Python Games

This directory contains small interactive games developed in Python.

These projects focus on programming fundamentals, game logic, user interaction, decision-making, randomization, and control flow.

---

## Projects

### Mad Libs Generator

**File:** `Madlibs_generator.py`

A word-based interactive game that creates humorous or creative stories using words provided by the user.

**Concepts:**

- String manipulation
- User input
- Variables
- Basic program flow

---

### Number Guessing Game

**File:** `Number_guessing_game.py`

A game in which the player attempts to guess a randomly selected number.

**Concepts:**

- Random number generation
- Loops
- Conditional statements
- User input
- Input validation

---

### Pig

**File:** `Pig.py`

A Python implementation of the Pig dice game.

**Concepts:**

- Randomization
- Game state
- Loops
- Conditional logic
- Score management

---

### Rock Paper Scissors

**File:** `rock_paper_scissors.py`

A command-line implementation of the classic Rock Paper Scissors game.

**Concepts:**

- Conditional logic
- Random selection
- User input
- Game rules
- Score tracking

---

### Tic Tac Toe

**File:** `tic_tac_toe.py`

A Python implementation of the classic Tic Tac Toe board game.

**Concepts:**

- Lists and data structures
- Game state management
- Conditional logic
- User interaction
- Win-condition checking
