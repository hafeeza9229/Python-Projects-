# Algorithms and Problem Solving

This directory contains Python projects focused on mathematical reasoning, algorithms, computational thinking, and problem solving.

The projects are designed to strengthen the ability to translate a problem into a logical and executable solution.

---

## Projects

### Math Problem Generator

**File:** `Math_problem_generator.py`

Generates mathematical problems for practice and problem-solving exercises.

**Concepts:**

- Arithmetic operations
- Randomization
- Conditional logic
- User interaction
- Problem generation

---

### Robot Return to Origin

**File:** `Robot_return_to_origin.py`

Determines whether a robot returns to its original position after processing a sequence of movements.

**Concepts:**

- Coordinate systems
- Movement tracking
- Algorithmic reasoning
- Conditional logic
- String processing

---

### Collinear Points Checker

**File:** `check_if_collinear_points.py`

Determines whether a set of points lies on the same straight line.

**Concepts:**

- Coordinate geometry
- Mathematical calculations
- Conditional logic
- Algorithm design
- Problem solving
